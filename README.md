# 基本設計書：広島観光地まとめサイト

- チーム番号：チーム05
- メンバー：有田昂平、稲留秀

## 課題
- **選んだ課題**：広島県の観光地として宮島・原爆ドーム以外の観光地があまり知られていない状態にある。
- **誰の課題か**：広島県
- **なぜこの課題を選んだか**：広島県には、歴史的な建造物、自然景観、地域ならではの文化、ダムや橋などの土木施設といった魅力的な観光資源が数多く存在する。しかし、宮島・原爆ドームに比べて情報が十分に知られておらず、観光客が訪れる機会を逃していると考えた。
そこで、広島県内のさまざまな観光地を一つのWebサイトにまとめ、観光地の魅力や見どころを分かりやすく発信することで、観光客の興味を引き出し、県内の幅広い地域への訪問を促したいと考えた。
- **（方法Bで選んだ場合のみ）元になった自治体課題**：広島県、宮島・原爆ドーム以外にも、素晴らしい観光地がたくさんある！！

## 0. 考えを整理する3つの問い
- **開発目的**：広島県内の知名度が低い観光地や公共土木施設などの情報をまとめ、観光客が新しい観光地を発見できるWebサイトを開発する。
- **想定ユーザ**：広島県を訪れる国内観光客・外国人観光客、広島県内の住民
- **機能**：
- 1.観光地一覧表示機能：広島県内のさまざまな観光地を一覧で表示する。写真、名称、所在地、簡単な説明を掲載する。

- 2.観光地詳細表示機能：観光地の見どころ、歴史、特徴、写真、アクセス方法などを表示する。ダムや橋など、インフラツーリズムにつながる公共土木施設も紹介する。

- 3.検索・絞り込み機能：地域やジャンルから観光地を検索できるようにする。例：自然、歴史・文化、インフラ、絶景、体験型観光など。

- 4：おすすめ観光地表示機能：宮島・原爆ドーム以外の観光地を積極的に紹介する。利用者が新しい観光地を発見できるようにする。

- 5.観光地マップ表示機能(可能であれば)：観光地の位置を地図上に表示する。周辺の観光地を確認し、複数の観光地を巡る計画を立てやすくする。

- 6.多言語対応機能：外国人観光客に向けて、観光地の基本情報を英語でも表示する。海外からの観光客にも広島県内の幅広い観光地を発信する。

## 1. ユーザーストーリー
- ストーリー1：【国内観光客】広島県を旅行する観光客として、宮島・原爆ドーム以外の観光地も訪れてみたいので、県内のさまざまな観光地を一覧から探し、興味のある場所の詳細を確認したい。
- ストーリー2：【外国人観光客】広島県を訪れる外国人観光客として、海外でも広島の魅力を知り、旅行先の候補を増やしたいので、観光地の写真や英語の説明を見て、訪問する場所を決めたい。
- ストーリー3：【観光客】旅行の計画を立てている観光客として、限られた時間で効率よく観光したいので、地図上で観光地の位置や周辺スポットを確認し、複数の観光地を巡るルートを考えたい。
- ストーリー4：【広島県内の住民】広島県内に住んでいる人として、身近な地域の新しい魅力を発見したいので、今まで知らなかった観光地や穴場スポットを検索して、休日のお出かけ先を探したい。
